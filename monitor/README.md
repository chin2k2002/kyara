# ぴあ公式リセール 出品監視スクリプト（通知専用）

指定したリセール出品一覧ページを定期的にチェックし、

- 対象日付（例: 8/26）
- 対象枚数（例: 2枚）

の両方に一致する出品を検知したら、デスクトップ通知・PC音・コンソール・
ログファイルで**お知らせするだけ**のスクリプトです。

**購入に進む・決済するといった操作は一切自動化していません。** 通知を
受け取った後、実際にページを開いて内容を確認し、購入〜決済は必ずご自身の
操作で行ってください。

## セットアップ

対象ページはJavaScriptで一覧データを後から描画するタイプのページのため、
素のHTML取得だけでは中身が読み取れません。そのため実際にブラウザで
レンダリングして読み取る **Playwright** を使用します。

```bash
cd monitor
python3 -m venv venv
source venv/bin/activate   # Windowsは venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium   # 初回のみ。Chromiumをダウンロードします（数百MB）
```

## ログイン（必要な場合）

対象ページはログインしていないと出品内容が表示されない可能性があります。
まず以下を実行し、開いたブラウザでご自身のアカウントにログインしてください。

```bash
python pia_resale_monitor.py --login
```

ログインが完了したら、ターミナルに戻ってEnterキーを押してください。
ログイン状態が `auth_state.json` に保存され、以降の監視で自動的に使われ
ます（初回の1回だけでOKです）。このファイルにはログインセッション情報が
含まれるため、**他人と共有したりリポジトリにアップロードしたりしないで
ください**（`.gitignore` で除外済みです）。

### `--login` でログインできない場合

環境によっては、ログイン画面（ticket-auth.pia.jp）側のBot対策により、
自動操作でのログインがブロックされることがあります
（`ERR_HTTP2_PROTOCOL_ERROR` 等で失敗する場合）。

この場合、**ログイン自体は自動化せず**、普段お使いのブラウザ（Edge等）
で人間の手でログインした後のプロファイル（ユーザーデータフォルダ）を
そのまま読み取り専用の監視に使う方法があります。

1. 普段のEdgeで `https://cloak.pia.jp/resale/item/list?...`（監視対象URL）
   を開き、いつも通りログインする
2. Edgeを完全に閉じる（すべてのウィンドウを閉じる）
3. Edgeのプロファイルフォルダ（既定は
   `C:\Users\<ユーザー名>\AppData\Local\Microsoft\Edge\User Data`）を、
   このスクリプト専用にコピーする（元のプロファイルは触らないように、
   コピーを使うことを推奨します）
4. コピーしたフォルダを指定して実行する

```bash
python pia_resale_monitor.py --profile-dir "C:\Users\<ユーザー名>\pia_edge_profile" --channel msedge
```

`--profile-dir` を指定すると `--login` や `auth_state.json` は使われず、
指定したプロファイルのCookie（＝人間が手動でログインした結果）がそのまま
使われます。ログインが自動操作に一切関与しないため、Bot対策の影響を
受けません。セッションの有効期限が切れたら、手順1〜3をやり直して
プロファイルを更新してください。

## 使い方

```bash
# 既定条件（8/26 / 2枚）で監視開始（間隔20秒）
python pia_resale_monitor.py

# 間隔や条件を変える
python pia_resale_monitor.py --interval 10 --date "8/26" --qty "2枚"

# まずはレンダリング後のHTML構造を確認したいだけの場合（通知はしない）
python pia_resale_monitor.py --dump-html

# うまく検知できない場合、ブラウザ画面を表示してデバッグ
python pia_resale_monitor.py --show
```

停止するときは `Ctrl+C` です。

## 動作の仕組みと注意点

- headless Chromiumで実際にページを開き、JS描画が終わるまで数秒待って
  から（`--render-wait` で調整可）、レンダリング後のHTMLを取得します。
- そのHTMLから、「class名に item / resale / card / list などが含まれる
  要素」の中に日付・枚数の両方が含まれるかを探します。見つからない場合は、
  ページ全文テキストを走査し、日付と枚数の文言が近い位置に出現している
  かで判定するフォールバック処理を行います。
- **このロジックは実際の出品がある状態のページを確認できない環境で作成
  した暫定版です。** 初回は `--dump-html` を実行して保存されたHTMLを
  確認し、意図通りに検知できそうか見てください。うまく検知できない場合は、
  該当する出品部分のHTML（`page_dump_*.html`）を共有していただければ
  `find_matching_blocks()` のロジックを調整できます。
- ポーリング間隔を極端に短く（数秒単位）すると、サイト側のアクセス制限や
  bot対策に引っかかる可能性があります。まずは既定の20秒程度から試し、
  問題なければ調整してください。ブラウザで毎回レンダリングする都合上、
  数秒間隔での安定動作は保証できません。
- 検知結果は `matches.log` に追記されます。

## 通知方法

- ターミナルへの表示 + ベル音
- Windows: PowerShell経由のデスクトップ通知（バルーン通知）+ ビープ音
- macOS/Linux: `plyer` 経由のデスクトップ通知（未対応環境では自動的にスキップ）
- macOS: 追加で通知センター経由のシステム通知
- **条件に一致する出品を検知すると、既定のブラウザで対象ページを自動的に
  開きます**（`--no-open-browser` オプションで無効化できます）。開くのは
  ページの表示までで、購入に進む操作はご自身で行ってください。

## スマホへの通知（ntfy）

PCの前にいなくてもスマホで気づけるように、[ntfy](https://ntfy.sh/) を
使ったプッシュ通知に対応しています。無料・アカウント登録不要です。

**セットアップ（初回のみ）**

1. スマホに ntfy アプリをインストール（[iOS](https://apps.apple.com/app/ntfy/id1625396347) /
   [Android](https://play.google.com/store/apps/details?id=io.heckel.ntfy)）
2. アプリを開き、「＋」（購読）から**他人に推測されにくい適当な文字列**を
   topic名として登録する（例: `pia-resale-abc123xyz`）。この文字列を知って
   いる人は誰でもその通知を受け取れる/送れる仕組みなので、簡単な単語は
   避けてください。

**実行時に指定**

```bash
python pia_resale_monitor.py --interval 5 --ntfy-topic "pia-resale-abc123xyz"
```

条件に一致する出品を検知すると、スマホに通知が届きます。**通知をタップ
すると、そのまま対象ページがスマホのブラウザで開きます**（購入操作の
自動化ではなく、ページを開くところまでです）。

# ぴあ公式リセール 出品監視スクリプト（通知専用）

指定したリセール出品一覧ページを定期的にチェックし、

- 対象日付（例: 8/26）
- 対象枚数（例: 2枚）

の両方に一致する出品を検知したら、デスクトップ通知・PC音・コンソール・
ログファイルで**お知らせするだけ**のスクリプトです。

**購入に進む・決済するといった操作は一切自動化していません。** 通知を
受け取った後、実際にページを開いて内容を確認し、購入〜決済は必ずご自身の
操作で行ってください。

## セットアップ

```bash
cd monitor
python3 -m venv venv
source venv/bin/activate   # Windowsは venv\Scripts\activate
pip install -r requirements.txt
```

## 使い方

```bash
# 既定条件（8/26 / 2枚）で監視開始（間隔15秒）
python pia_resale_monitor.py

# 間隔や条件を変える
python pia_resale_monitor.py --interval 10 --date "8/26" --qty "2枚"

# まずはページのHTML構造を確認したいだけの場合（通知はしない）
python pia_resale_monitor.py --dump-html
```

停止するときは `Ctrl+C` です。

## 動作の仕組みと注意点

- ページ内のテキストから、「class名に item / resale / card / list など
  が含まれる要素」の中に日付・枚数の両方が含まれるかを探します。見つから
  ない場合は、ページ全文テキストを走査し、日付と枚数の文言が近い位置に
  出現しているかで判定するフォールバック処理を行います。
- **このロジックは実際のページHTMLを確認できない環境で作成した暫定版
  です。** 初回は `--dump-html` を実行して保存されたHTMLを確認し、
  意図通りに検知できそうか見てください。うまく検知できない場合は、
  該当する出品部分のHTML（`page_dump_*.html`）を共有していただければ
  `find_matching_blocks()` のロジックを調整できます。
- ポーリング間隔を極端に短く（数秒単位）すると、サイト側のアクセス制限や
  bot対策に引っかかる可能性があります。まずは既定の15秒程度から試し、
  問題なければ調整してください。
- 検知結果は `matches.log` に追記されます。

## 通知方法

- ターミナルへの表示 + ベル音
- OS標準のデスクトップ通知（`plyer` 経由。Windows/Mac/Linuxに対応、
  未対応環境では自動的にスキップされます）
- Windows: 追加でビープ音
- macOS: 通知センター経由のシステム通知

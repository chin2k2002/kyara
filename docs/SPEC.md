# PowerPoint 自動スライドショー 仕様書 (v1)

指定した曜日・時間帯ごとに、指定した PowerPoint または動画を自動で全画面再生する Windows 常駐アプリ。

## 1. 実行環境・方式

- OS: Windows(PowerPoint インストール済み)
- 言語: Python + pywin32(PowerPoint を COM で操作)
- 形態: 設定 GUI と常駐スケジューラーを兼ねた 1 つのアプリ
  - タスクトレイに常駐。Windows ログオン時に自動起動
  - GUI を閉じてもトレイに残り、スケジュール実行を継続
- 音声: 出力しない(動画は常時ミュート)

## 2. スケジュール

### 2.1 スケジュール枠の項目

| 項目 | 内容 |
|---|---|
| 曜日 | 月〜日を複数選択 |
| 開始時刻 / 終了時刻 | 日またぎ(例 22:00〜翌 06:00)を許可 |
| ファイル | PPT(.pptx/.ppt)または動画(.mp4 等)。指定フォルダ内から GUI で選択 |
| 1 スライドの表示時間 | 枠ごとに指定。初期値 60 秒、下限 1 秒、上限 1 時間。秒または 分:秒で入力 |

### 2.2 既定ファイル(空き時間用)

- どの枠にも入っていない時間は、既定ファイルを繰り返し再生する
- 既定ファイルにも「ファイル」「1 スライドの表示時間」を設定する

### 2.3 重複の扱い

- 入っている枠の時間帯は占有され、重なる枠は登録できない(GUI 上で選択不可)
- 登録済みの枠はドラッグで移動・リサイズできない。変更は編集ダイアログから行う

## 3. スケジュール画面(GUI)

- Outlook / Google カレンダー風の週表示(縦軸: 時刻、横軸: 曜日)
- 入っている枠はブロック表示(ファイル名・時間帯。ファイルごとに自動で色分け)
- 空き時間は灰色で「既定: ○○」と表示
- 空き枠をドラッグして新規登録 → ダイアログでファイル・曜日・表示時間を指定
- ダブルクリックで編集、右クリックで削除
- 現在時刻に赤線を表示し、再生中のブロックを強調
- 日またぎの枠は日ごとに 2 分割して表示

## 4. 再生ルール

1. 開始時刻になったら対象ファイルを全画面で再生し、終了時刻まで繰り返す
2. PPT:
   - 1 スライドをスケジュール枠で指定した秒数表示して自動送り。最後まで行ったら先頭に戻る
   - ファイル内のスライド切替タイミング設定は無視し、枠の秒数に統一する
   - スライド上に動画があるページは、動画を最後まで再生してから次へ進む。動画が設定秒数より短い場合は設定秒数まで待つ
3. 動画単体: 終了時刻までループ再生(表示秒数の指定は不要)
4. 終了時刻になったら次の枠(なければ既定ファイル)へ切り替える
5. ファイルが存在しない・開けない(パスワード付き等)場合は既定ファイルに退避し、ログに記録する
6. 再生中や次回予定のファイルが上書きされた場合は、次のループまたは次の切替時に読み直す

## 5. 操作

- 全画面表示中にマウスクリックすると、スライドショーを終了する
- 終了後は、次のスケジュール切替時刻に自動で再開する

## 6. ログ

- 切替、エラー(ファイル不在・開けない等)をログファイルに記録する
